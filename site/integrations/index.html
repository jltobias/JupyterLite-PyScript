The file is the interface

One selection.
Three GIS destinations.

Exchange a real GeoJSON file across independent browser applications. You do not need a Python bridge, a shared runtime or a package installation.

Use the same file in each tool: six synthetic NYC points at 08:00, in longitude/latitude (EPSG:4326). No observation represents a real person, taxi trip or health record.

1. Export from a PyScript lab

  1. Open the 2D map and wait for “Ready.”
  2. Select 08:00. Check that the displayed count is 6.
  3. Click Download GeoJSON. Keep synthetic-nyc-hour-8.geojson. Open it in a text editor if you want to inspect its metadata and six features.

2. Import into a browser GIS

  • GeoLibre ↗: drag the downloaded GeoJSON onto the map, then zoom to the layer. Check six points and the hour, value and simulated attributes. See GeoLibre's documented URL handoff for a public-file alternative.
  • RustGIS ↗: choose Home → Add → Add Data and select the downloaded GeoJSON. Inspect the attribute table and zoom to the imported layer. See supported data formats. The separate RustGIS Python library targets native CPython; this lesson does not install it in Pyodide.
  • JupyterGIS browser preview ↗: upload the GeoJSON with the file browser's upload button. In the same directory, choose Other → GIS File in the launcher to create a .jGIS document. In its layer panel choose + → Add Vector Layer → GeoJSON, set Path to your uploaded filename, then confirm Ok. Right-click the layer and choose Zoom to Layer. Inspect the point count and fields. See JupyterGIS documentation.

Import labels may change upstream. Consult each tool’s linked documentation if a menu moves. All three destinations are external applications; this repository neither controls them nor shares Python memory with them.

3. Verify the handoff

Your layer should contain six features, each with hour = 8 and simulated = true. Coordinates should be near longitude −74 and latitude 40.7. If the points appear in the wrong place, confirm longitude comes first and select EPSG:4326 if prompted.

Repeat the export at 00:00. A valid empty FeatureCollection has zero features; a GIS may show an empty layer or decline to display it. That is an empty selection, not a broken download.

Know the boundaries

JupyterGIS Lite is a browser preview. Do not expect real-time collaboration, QGIS project conversion, server raster tiling or functioning STAC search there. Keep the original GeoJSON download: browser storage can be cleared and applications use separate virtual filesystems.
